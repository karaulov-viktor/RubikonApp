# RubikonApp — пакет v3 «Кормление, диеты, вес» (поверх v2)

Дата: 2026-09-14. Ставится ПОВЕРХ установленного v2 (или начисто).
Ваша база data/rubikon.db НЕ трогается — миграция только ДОБАВЛЯЕТ
колонки (feedings.grams, diets.goal/kcal/target_weight).

## Что нового

1.  КОРМЛЕНИЕ = РАСЧЁТ НОРМЫ (как в ветеринарных калькуляторах
    Royal Canin / Veterical / WSAVA):
    - иконка КАЛЬКУЛЯТОРА в шапке секции «Кормление» открывает
      панель: вес (подставляется из последнего замера), калорийность
      корма ккал/100 г, переключатели «Стерилизован» и «Активность»;
    - формула: RER = 70 x вес^0.75, MER = RER x коэффициент
      (котёнок 2.5 / щенок до 4 мес 3.0 / молодняк 2.0 / кошка
      стер. 1.2 / кошка 1.4 / собака стер. 1.6 / собака 1.8 /
      пожилые ниже / снижение веса 0.8-1.0);
    - результат: ккал/сутки, граммы корма/сутки, число кормлений по
      возрасту (до 4 мес — 4 раза, 4-6 — 3, взрослые — 2), время
      приёмов, норма воды;
    - кнопка «Применить к расписанию» заменяет расписание на
      правильные кормления с порциями в граммах (08:00 · 37 г · ...).

2.  ДИЕТА = ПОДБОР ПО ПРОФИЛЮ:
    - иконка ЛАМПОЧКИ в шапке секции «Диета» подбирает варианты по
      виду/возрасту/стерилизации/динамике веса: рацион роста для
      котят-щенков, снижение веса при наборе (+5% между замерами),
      лёгкий рацион стерилизованным, поддержка почек пожилым кошкам,
      суставов — пожилым собакам;
    - «Начать» подставляет параметры в форму — проверьте и нажмите
      «Начать»: создастся диета с целью и калорийностью, а время
      кормлений уйдёт в расписание С порциями.

3.  ВЕС И ДИНАМИКА — починен график:
    - был: пустая область (рисование до расчёта размера виджета);
    - стало: белая карточка графика с сеткой, линией и точками;
      перерисовка при любом изменении размера; работает даже с одним
      замером (точка по центру);
    - вместо квадратиков «(□ 5.00 кг)» — слова: «рост +0.50 кг» /
      «снижение 0.50 кг» (юникод-стрелки не рендерятся Roboto);
    - в статистике: мин / макс / разница / изменение за период.

4.  БЕЛЫЕ ЭКРАНЫ:
    - все карточки белые с явным elevation: 0; фон окон — белый
      литералом (даже если theme.py старый);
    - исправлены НАЛОЖЕНИЯ ТЕКСТА (заголовок «Диета» поверх
      подсказки, подсказки полей в чужие поля): высота текстовых
      блоков теперь подстраивается под текст, формы разнесены по
      рядам, подсказки укоротлены.

5.  НАДЁЖНОСТЬ:
    - встроен FBO-патч KivyMD (экран больше не падает «FBO
      Initialization failed 36054» на слабых GPU — фикс
      fix_kivymd_fbo.py теперь применяется сам при каждом старте);
    - при старте в консоли печатается строка самопроверки:
      [RubikonApp] KivyMD 2.0.0, тема whitegreen-3
      Если тема НЕ whitegreen-3 — вы не скопировали models/theme.py.

## УСТАНОВКА (2 шага)

1)  Скопируйте ВСЁ содержимое архива поверх D:\Rubikon_vet
    (с заменой файлов). Новое: models/nutrition.py.

2)  ОБЯЗАТЕЛЬНО (один раз):
        cd D:\Rubikon_vet
        .\venv\Scripts\python.exe -m pip install -r requirements.txt
    Причина: requirements жёстко фиксирует kivymd==2.0.0, а у вас,
    судя по прошлым логам, стоит KivyMD 2.0.1.dev0 — на dev-версиях
    карточки могут рисоваться с тонировкой вместо белого.

Запуск: run.bat (как раньше).

## ЧЕК-ЛИСТ ПРОВЕРКИ (5 минут)

 1. При старте в консоли: «тема whitegreen-3» и нет красных ошибок.
 2. Профиль -> питомец: карточки и фон — БЕЛЫЕ, текст нигде не
    наезжает на текст.
 3. Секция «Кормление»: иконка калькулятора -> панель с весом и
    калорийностью корма -> появились ккал и граммы. Переключите
    «Стерилизован» — цифры изменились.
 4. «Применить к расписанию»: в расписании появились строки вида
    «08:00 · 37 г · норма 74 г/сутки».
 5. Секция «Вес»: запишите два разных веса — появилась линия с
    точками; под ней «мин/макс/разница»; рядом с последним замером —
    «рост/снижение» СЛОВАМИ, без квадратиков.
 6. Секция «Диета»: иконка лампочки -> варианты с пояснениями
    «почему»; «Начать» -> поля заполнились -> «Начать» в форме ->
    карточка активной диеты с калорийностью и прогрессом.
 7. Калькулятор и календарь (старые экраны) работают как раньше.
 8. Каталог: 61 препарат на месте.
