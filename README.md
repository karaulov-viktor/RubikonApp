# RubikonApp — пакет v2 «Восстановление + Питомцы» (rubikon_pets_v2)

## Что случилось с v1 (честно)

Пакет v1 был собран на заготовке-скелете и затер часть готового
функционала: каталог перестал видеть препараты, калькулятор стал
заглушкой, а профиль падал с `KeyError: 'birth_date'` (новый код
ожидал дату рождения, которой нет у старой таблицы питомцев).

Этот пакет v2 собирает ВСЁ вместе:

- **Старый функционал возвращён целиком** (код спринтов 1–2.6 не менялся):
  каталог 61 препарата с фото и поиском, карточка препарата,
  лечение и назначения, будильники, календарь лечения,
  история назначений, калькулятор доз.
- **Новые фичи «Питомцев» остались**: карточки нового дизайна,
  личная страница (аватар на всю ширину), галереи фото и видео
  (видео играет прямо в приложении), дата рождения + поздравление,
  лекарства и кормление, диеты с прогрессом, график веса (Canvas),
  дисклеймер первого запуска, системные уведомления при закрытом
  приложении, подсветка нижнего меню, единый файл цветов.
- **Миграция базы**: при первом запуске таблица питомцев получит
  новую колонку `birth_date`; ваши текущие питомцы и все 61 препарат
  НЕ тронуты. Дату рождения старым питомцам можно внести через
  карандашик на личной странице.
- **Мост**: на личной странице питомца появилась зелёная кнопка
  «Лечение и назначения» — это прежний экран лечения (выбор препарата,
  будильники, история). Тап по карточке лечения открывает детали.

## Как ставить

1. Закройте приложение.
2. Скопируйте СОДЕРЖИМОЕ папки из архива поверх `D:\Rubikon_vet`
   (с заменой файлов). Папки из архива кладутся ВНУТРЬ существующих
   `models/`, `screens/`, `kv/`.
3. Ничего дополнительно ставить НЕ нужно (ffpyplayer уже установлен).
4. Запустите как обычно: `run.bat` или
   `.\venv\Scripts\python.exe main.py`

База `data/rubikon.db` в архиве НЕТ — ваша останется как была.
Перед первым запуском приложение само сделает бэкап в `backup/`.

## Чек-лист проверки (10 тестов)

1. Запуск: заставка → дисклеймер (один раз) → каталог;
   в каталоге 61 препарат с фотографиями.
2. Поиск в каталоге: «азитро» → остаются препараты АЗИТРО*.
3. Тап по препарату → карточка с инструкцией, текст зелёный.
4. Калькулятор: вес 10, доза 5, концентрация 2.5 → «50 мг / 20 мл».
5. Профиль: карточки Кузи и Тишки на месте (белые, зелёные акценты);
   тап → личная страница с фото на всю ширину.
6. «+» → новый питомец: вид, порода, ДАТА РОЖДЕНИЯ (спиннеры), фото.
7. Личная страница → «Лечение и назначения» → выбор препарата
   (для кошки — только подходящие) → «Записать» → календарь
   предзаполнен → сохранить будильник → в назначенное время звук
   и уведомление.
8. На личной странице: добавить фото и mp4-видео → видео играет
   прямо в приложении.
9. Диета: создать (название + срок + время кормления) → прогресс-бар;
   запись веса → после двух замеров появляется график.
10. Профиль → «Включить напоминания при закрытом приложении» →
    закрыть приложение → напоминание приходит от Windows
    (если задача не создалась — один запуск от администратора).

## Если что-то пойдёт не так

- Текст ошибки из консоли пришлите в чат — разберём.
- Бэкапы базы: `backup/rubikon.db.bak-...` (создаются при каждом
  старте, хранятся последние 20).
- Полный откат: напишите мне — вернём прежние файлы точечно
  (сами файлы прежней версии сохранились у меня).
