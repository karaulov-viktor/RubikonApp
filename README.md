# RubikonApp — пакет v4 «Просмотр медиа, вес списком, палитра whitegreen-4»

Дата: 2026-09-15. Ставится ПОВЕРХ установленного v3 (или начисто).
Ваша база data/rubikon.db НЕ трогается — миграции не менялись.

## Что нового

1.  ПРОСМОТР ФОТО (починено «просмотр фотографий не открывается»):
    - тап по плитке в галерее открывает фото НА ВЕСЬ экран;
    - стрелки назад/вперёд листают всю галерею, сверху счётчик
      «Фото 2 из 12», внизу имя файла;
    - фото показывается ЦЕЛИКОМ (без обрезки, как было в плитках);
    - закрытие — стрелка «назад» вверху слева.

2.  ВИДЕО (починено «видео не загружаются / установите ffpyplayer»):
    - в списке больше НЕТ плееров — раньше все клипы начинали
      грузиться одновременно и вешали экран; теперь список лёгкий:
      иконка play + имя файла;
    - тап по клипу открывает полноэкранный плеер, видео грузится
      ТОЛЬКО в момент открытия, один плеер на всё приложение;
    - при закрытии плеера файл выгружается из памяти;
    - если ffpyplayer не установлен, показывается ПОДСКАЗКА С ТОЧНОЙ
      КОМАНДОЙ установки (см. «Установка», шаг 3).

3.  ВЕС — ГРАФИК УБРАН (просьба владельца: отображался некорректно):
    - остался ТОЛЬКО список замеров: дата — вес, свежие сверху;
    - у каждого замера динамика словами: «рост +0.10» / «снижение
      0.25» (юникод-стрелки не рендерятся Roboto — урок v2);
    - сводка над списком: всего замеров / мин / макс / разница /
      изменение за период;
    - запись веса работает как раньше.

4.  НОВАЯ ПАЛИТРА whitegreen-4 (просьба владельца: бирюза и мята
    надоели):
    - приложение БЕЛОЕ, шрифты ТЁМНО-ЗЕЛЁНЫЕ (#1B3A28);
    - акценты — глубокий тёмно-зелёный #14532D вместо травяного
      #177300; заголовки, кнопки, иконки, нижнее меню — всё в нём;
    - мятные подложки заменены почти белыми нейтральными (#F1F5EF) —
      карточки остаются различимы, но «мятного» цвета больше нет;
    - старые экраны (каталог, калькулятор, календарь, лечение)
      перекрасились автоматически — цвета заданы только в
      models/theme.py;
    - при старте в консоли печатается: тема whitegreen-4.

## УСТАНОВКА (3 шага)

1)  Скопируйте ВСЁ содержимое пакета поверх папки проекта
    (с заменой файлов). Новое: screens/media_viewer.py,
    kv/media_viewer.kv.

2)  Проверьте models/theme.py: в начале файла должно быть
    whitegreen-4. Если остался старый — скопируйте из пакета.

3)  ОБЯЗАТЕЛЬНО для видео (один раз, в venv проекта):
        cd <папка проекта>
        .\venv\Scripts\python.exe -m pip install ffpyplayer
    Проверка установки:
        .\venv\Scripts\python.exe -m pip show ffpyplayer

Запуск: run.bat (как раньше).
