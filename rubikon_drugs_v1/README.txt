  • Виды нормализованы под поиск приложения:
    Собаки→Собака, Кошки→Кошка, Индейка→Птица;
    КРС, Свинья, МРС, Лошадь оставлены для будущего.
    Формат поля: «Собака,Кошка,КРС» — как в seed-данных.
  • Инструкция (HTML из Tilda) сконвертирована в фирменный Kivy-markup:
    зелёные заголовки секций, «•»-списки, дисклеймер в конце.

    не указана. Заполни руками, когда будешь вносить дозы.

КАК ЗАГРУЗИТЬ В СВОЙ ПРОЕКТ (SQLiteStudio)
------------------------------------------
  ШАГ 1. Скопируй папку img/drugs/ целиком в проект:
         I:\Rubikon_vet\img\drugs\ (61 файл)

  ШАГ 2. Открой в SQLiteStudio СВОЮ базу I:\Rubikon_vet\data\rubikon.db

  ШАГ 3. Инструменты → Открыть SQL редактор. Открой файл
         insert_drugs.sql (кнопка папки в панели редактора) и нажми
         Выполнить (F9).

         Скрипт внутри транзакции делает:
           DELETE FROM drugs;                              ← старые 10 уйдут
           DELETE FROM sqlite_sequence WHERE name='drugs'; ← счётчик id с 1
           + 61 INSERT

  ШАГ 4. Проверка:
           SELECT COUNT(*) FROM drugs;   → должно быть 61

  ШАГ 5. Запусти приложение: Каталог должен показать 61 препарат
         с фото, поиск и «Подходящие препараты» работают сразу.

  ⚠ ВАЖНО про каскадное удаление: вместе со старыми 10 препаратами
    будут удалены НАПОМИНАНИЯ, ссылающиеся на них (FK ON DELETE
    CASCADE). Если в календаре есть напоминания на Аспирин и пр. —
    они сотрутся. Бэкап базы при старте приложения всё равно
    создаётся в backup/.

  ⚠ git: data/rubikon.db затрекан — после импорта в git status будет
    бинарный дифф. Это та самая мина №3; на следующем занятии
    выведем базу из-под git (git rm --cached + .gitignore).


ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
------------------------
  • Откат: backup/rubikon.db.bak-<дата> (создаётся при каждом старте).
  • drugs.db — та же база отдельно: можно открыть в SQLiteStudio
    параллельно и подсмотреть/скопировать любую строку.
  • Скрипт можно выполнять повторно: он сначала стирает каталог,
    потом вставляет заново (идемпотентен относительно drugs).
    Питомцы/напоминания/назначения по другим таблицам не трогаются
    (кроме каскада по удаляемым препаратам).
