RUBIKON — редизайн «PetsHealth» v1 + сброс поиска
=================================================

ЧТО ВНУТРИ
----------
  main.py                  — тема Cyan, светлый фон, белый тост
  models\theme.py           — НОВЫЙ файл: ВСЕ цвета приложения в одном месте
  kv\*.kv (8 файлов)        — редизайн всех экранов
  screens\*.py (5 файлов)   — сброс поиска + цвета карточек (+ старые фиксы)
  models\image_utils.py     — фикс путей к фото (из пакета imagefix)
  recolor_drug_markup.sql   — ОПЦИЯ: заголовки в инструкциях зелёные → бирюзовые

УСТАНОВКА (7 файлов поверх I:\Rubikon_vet\ с сохранением структуры)
-------------------------------------------------------------------
1. Скопируй папки из архива В КОРЕНЬ проекта:
   main.py, models\, kv\, screens\
   На вопрос о замене — «Да, заменить».
2. Запусти приложение: D:\PYTHON\python.exe I:\Rubikon_vet\main.py

База и фото НЕ трогаются — пакет только про внешний вид и поиск.

ЧТО ПОМЕНЯЛОСЬ (проверь глазами)
--------------------------------

  - акцент: зелёный → бирюзовый (#2FA5C5) — кнопки, FAB, активная вкладка
  - splash: вместо зелёного заливки — светлый фон, бирюзовый «Агент»
  - профиль: карточки белые, слева заголовок «Мои питомцы»

ФИКС ПОИСКА (главная функциональная правка)
-------------------------------------------
Введи в поиске «азитро» → открой любой препарат → вернись назад:
строка поиска теперь ПУСТАЯ, каталог показывает все 61 препарат.

ОПЦИЯ: перекраска заголовков в инструкциях
------------------------------------------
Инструкции препаратов лежат в БАЗЕ с зелёными заголовками [color=#177300].
Чтобы они стали бирюзовыми — выполни в SQLiteStudio recolor_drug_markup.sql
(в скрипте есть откат). Не хочешь — оставь зелёными, всё будет работать.
