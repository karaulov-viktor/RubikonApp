RUBIKON — прозрачные фото препаратов (PNG), пакет v1
====================================================

ЧТО ЭТО
-------
Все 61 фото препаратов переделаны: белый фон удалён, добавлена
прозрачность (PNG с альфа-каналом). Каждое фото дополнительно обрезано
по краям товара — флакон/коробка теперь занимают всю карточку, а не
плавают в белом поле. Проверить всё разом можно файлом preview_all.png.

СОСТАВ АРХИВА
-------------
  img\drugs\*.png            — 61 фото с прозрачным фоном
  update_drugs_img_png.sql   — переключает пути в базе с .jpg на .png
  preview_all.png            — контрольный лист для визуальной проверки

УСТАНОВКА (5 минут)
-------------------
1. Скопируй СОДЕРЖИМОЕ папки img\drugs\ из архива в
   I:\Rubikon_vet\img\drugs\
   Должно получиться: I:\Rubikon_vet\img\drugs\azitrikon_rastvor.png
   и ещё 60 файлов .png рядом.
   Старые .jpg удалять не обязательно — база перестанет на них ссылаться.

2. Открой I:\Rubikon_vet\data\rubikon.db в SQLiteStudio.
   Инструменты -> SQL-редактор -> вставь текст из update_drugs_img_png.sql
   -> синяя кнопка Выполнить.
   Скрипт сам в конце выведет остаток .jpg — должно быть 0.

3. Запусти приложение и открой каталог препаратов.

ПРОВЕРКА (если хочешь убедиться руками)
---------------------------------------
SELECT COUNT(*) FROM drugs WHERE image LIKE '%.png';  -- 61
SELECT COUNT(*) FROM drugs WHERE image LIKE '%.jpg';  -- 0

ПРИМЕЧАНИЯ
----------
- JPEG прозрачность не умеет в принципе, поэтому переход на PNG обязателен.
- Пакет дружит с фикс-паком imagefix (models/image_utils.py): тот резолвит
  путь через BASE_DIR и не смотрит на расширение, так что .png подхватится.
- Kivy грузит PNG с альфой штатно, карточка просвечивает сквозь фон.
